# 🍽️ TasteTrail

### Smart Restaurant Discovery & Recommendation Platform

TasteTrail is a web-based restaurant discovery platform designed to help users find suitable restaurants when they are in a new or unfamiliar location. Instead of blindly choosing a restaurant, users can explore nearby options based on cuisine, budget, distance, ratings, dining preferences, and other factors.

The platform combines restaurant discovery with an interactive map and navigation features to make choosing and reaching a restaurant easier.

---

## 📌 Project Overview

Finding a good restaurant in an unfamiliar place can be difficult. Users often depend on random recommendations or search through multiple platforms to compare restaurants.

**TasteTrail** aims to provide a simple and user-friendly interface where users can:

- Discover nearby restaurants
- Search restaurants by name or cuisine
- Filter restaurants according to their preferences
- Compare different restaurants
- View restaurant details
- Locate restaurants on an interactive map
- Get navigation information
- Save favourite restaurants
- Explore recommendations based on dining preferences

---

## 🎯 Objectives

The main objectives of TasteTrail are:

- To simplify restaurant discovery in unfamiliar locations
- To help users compare multiple restaurant options
- To provide location-based restaurant suggestions
- To provide an interactive map for easier navigation
- To create a clean, responsive and user-friendly interface
- To provide personalized restaurant discovery based on user preferences

## ✨ Features

### 🔍 Restaurant Search
Search for restaurants using:
- Restaurant name
- Cuisine
- Keywords

### 🎯 Smart Filters
Users can filter restaurants based on:
- Cuisine
- Budget
- Distance
- Rating
- Open/closed status
- Dietary preferences
- Facilities

### 📍 Location-Based Discovery
Users can:
- Enter a location manually
- Use their current location
- Discover restaurants near a selected location

### 🗺️ Interactive Map
Restaurants can be displayed on an interactive map so users can easily understand their locations.

### 🏪 Restaurant Details
Each restaurant can have information such as:
- Restaurant name
- Cuisine
- Rating
- Price range
- Address
- Opening hours
- Facilities
- Photos
- Menu highlights

### ⚖️ Restaurant Comparison
Users can select multiple restaurants and compare important details such as:
- Rating
- Price
- Distance
- Cuisine
- Facilities

### ❤️ Favourites
Users can save restaurants they are interested in for future reference.

### 🧭 Navigation
Users can view the restaurant location and access route/navigation information.

### 💡 Recommendations
TasteTrail can provide restaurant suggestions based on:
- User preferences
- Dining purpose
- Mood
- Budget
- Cuisine
