This project generates restaurant "photos" as lightweight inline SVG
placeholders (see placeholderImage() in js/main.js), so no external
image files are required to run the site.

Drop real restaurant photos in this folder and update placeholderImage()
in js/main.js (or the "image" field in js/restaurants.js) to point to
them, e.g. "assets/images/cafe-noir.jpg", if you'd like real photos
later.
